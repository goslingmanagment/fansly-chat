GooseMuse

Расширение для Firefox, которое поможет вести чаты быстрее и интереснее

Установить GooseMuse
Как установить
  1. Откройте эту страницу в Firefox
  2. Нажмите кнопку «Установить GooseMuse»
  3. Разрешите установку во всплывающем окне
  4. Готово! Обновления будут приходить автоматически
