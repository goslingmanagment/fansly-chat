### Core deploy — безопасное применение migration 0106

До первого применения Core migration `0106_ai_generation_content_fan_ref.sql` в
окружении проверить `schema_migrations` и `pg_index.indisvalid`. Если `0106` ещё
не применена, заранее выполнить metadata-only column add и неблокирующую сборку
индекса отдельными autocommit-командами (не внутри transaction block):

```sql
ALTER TABLE ai_generation_content ADD COLUMN IF NOT EXISTS fan_ref text;
CREATE INDEX CONCURRENTLY IF NOT EXISTS ai_generation_content_page_fan_idx
  ON ai_generation_content (page_id, fan_ref) WHERE fan_ref IS NOT NULL;
```

Затем запускать обычный migration runner: его plain `CREATE INDEX IF NOT EXISTS`
станет быстрым no-op. Уже опубликованную forward-only migration не переписывать;
новая migration после 0106 не может устранить блокировку внутри самой 0106.

### BL-008 — длинное тире (ЗАКРЫТО 2026-07-28)

Закрыто в тот же день: core Decision #189 (PR #35) + ext E63 (PR #58/#59).
Обе половины в main, **не развёрнуты**: ждут деплоя ядра и релизной сборки.

Что оказалось на деле, если придётся возвращаться:

- **Главным источником был не текст шаблонов, а маркер вложения.** Оба конца
  собирали `[… — PPV $X.XX, state]` настоящим тире (ext `src/shared/transcript.ts`
  `ppvSuffix`, core `prompts/transcript/normalize.ts`), и он приезжал в КАЖДУЮ
  генерацию по разу на платное вложение, раньше любой инструкции. Теперь дефис.
  Грамматику дословно цитируют fast-reply, help-me, improve-draft, ping — пять
  точек двигаются только связкой, иначе цитата перестаёт описывать живой тег.
- **Чистки исходников было мало.** Ответы коуча это вывод модели, а единственный
  явный запрет лежал ВНУТРИ бандла личности Лоры, то есть действовал на
  reply-фичи и не действовал на коуч, рекапы, разбор чата и войс — владелец
  продолжал видеть тире в коуче уже после чистки. Запрет переехал в блок
  WRITING RULES обеих safety-преамбул (`builder.ts`) — единственный текст, общий
  для всех фич, и туда же класть будущие общие правила стиля.
- Цена: у коуча стало ~430 символов меньше от потолка 300k (редьюсер справляется
  штатно), а упакованная под потолок фикстура теперь считает набивку от
  `ANALYSIS_SAFETY_PREAMBLE.length`, иначе молча срезала бы рекап, который сама
  же проверяет.
- Осознанно НЕ сделано: `normalizeDashes` в санитайзере расширения
  (`src/shared/reply-output.ts`) как страховка на случай, если модель проскочит
  мимо запрета. Готовая функция лежит в ядре
  (`prompts/output/reply-output.ts`) и там ничем не вызывается — санитайз живёт
  на клиенте. Решать после того, как посмотрим на живой вывод после деплоя.
  Десктоп (`~/code/chatgoose_desktop_fable`) на тот же разрыв не проверялся.
