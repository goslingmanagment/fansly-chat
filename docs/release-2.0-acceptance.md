По просьбе пользователя создан новый ограниченный ключ ElevenLabs. Проверка
через серверный service proxy вернула HTTP 200 для подписки и нужного голоса,
но статус подписки — `past_due`. Новый ключ не применён к Hub; старый остаётся
в работе. Пользователь ответил «Оплачу этот аккаунт»; завершение оплаты ещё
не подтверждено. **Оплата агентом не разрешена этим чеклистом.** Подробности
подготовки ключа — в `release-2.0-voice-sdk-readiness.md`. Упоминание Voice
в документации означает наличие реализации, а не завершённую платную приёмку.

Владелец разрешил публикацию сборки 2.0.0 и подготовленного Telegram-анонса.

голоса существует. Во время публикации не меняются ключ, флаги Voice и биллинг,
не выполняются платная генерация и взаимодействие с Firefox.
